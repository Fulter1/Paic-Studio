PAIC Studio 6.0

نسخة معاد بناؤها من الصفر.

التشغيل:
1) ارفع المجلد كما هو إلى Vercel أو أي استضافة Static.
2) أو شغل محليًا: python3 -m http.server 8080
3) افتح http://localhost:8080

كل الحفظ محلي وسريع. لا يحتاج حسابًا أو Supabase.
PDF وPNG يتم إنشاؤهما محليًا داخل المتصفح من رسم SVG مستقل، لذلك لا توجد مكتبة خارجية مطلوبة للتصدير.
